# Adresteia

Projek belajar Java.

## Struktur Folder

```
adresteia/
├── src/          # Source code Java
│   ├── App.java
│   ├── belajarjava/
│   ├── dasar/
│   └── kasir/
├── notes/        # Catatan belajar
├── lib/          # Dependencies (JAR)
├── bin/          # Output compiled (.class)
└── html/         # File HTML pendukung
```

## Cara Menjalankan

```bash
# Compile & run dengan VS Code Java extension
# Atau manual:
javac -d bin src/App.java
java -cp bin App
```
